# A fast, lightweight password manager for Vaultwarden

Litewarden is a free, open-source extension for Chrome, Brave and Edge, for people who run their own
[Vaultwarden](https://github.com/dani-garcia/vaultwarden) server. It also works with Bitwarden servers.

![Litewarden's popup next to its in-page menu on a sign-in form](img/hero.png)

- **Fast to open.** The popup is ready in about 100 ms, even with thousands of items.
- **One key to fill.** The logins for the site you're on come first, and Enter fills the top one.
- **Out of the way.** The in-page menu opens only when you click its icon, and it never covers a form field or
  button.
- **2FA codes built in**, PIN unlock, save and update prompts, live sync and a full keyboard workflow.
- **Private.** End-to-end encrypted, no telemetry, and it talks only to your own server.
